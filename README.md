# Programaci-n-III-Pr-ctico-N.-2
​Integración de JavaScript y PHP​
PASO DE INTALACIÓN
1. Clonar el repo.
2. Descargar el sql y importarlo en la base de datos.
3. Hacer el --- composer install ---, para instalar todas las dependencias de PHP que el proyecto necesita para funcionar.
4. Configurar el archivo de entorno: Duplicar el archivo .env.example, renombrarlo a .env y configurar las credenciales de la base de datos que importaste en el paso 2.
